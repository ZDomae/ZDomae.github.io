# Access control

> This page describes what each role can do. Use it to choose the right role before you start a task.

[[toc]]

## Prerequisites

- You are signed in to the product. No special role is required to read this page, but you need the listed role to perform the actions in each table.

## Account Admin

Use this role for engineers who set up the product for new customers. It has full configuration access.

| Section | What this role can do |
| --- | --- |
| Admin Portal | Create and manage global settings and classes. |
| Product | Manage and edit all product sections. |
| Users & Accounts | Create and manage users and groups. |
| Assessments | Create and manage operational acceptance testing assessment types. |
| Reports | Import and export Power BI reports and templates. |
| Dashboards | Import and export dashboards. |

### Verification

If you have the **Account Admin** role, you see **Admin Portal** > **Settings** and **Product** with edit controls.

## Account Compliance Officer

Use this role for users who manage the **Compliance** area of the product. Access is scoped to compliance.

| Section | What this role can do |
| --- | --- |
| Admin Portal | Manage **Compliance** classes. |
| Product | View only (restricted). |
| Users & Accounts | Create and manage users and groups for the **Compliance** product. |
| Assessments | Manage existing **Compliance** assessment types. |
| Reports | Import and export Power BI reports and templates. |
| Dashboards | Import and export dashboards. |

### Verification

If you have the **Account Compliance Officer** role, **Admin Portal** shows only compliance-related classes and **Product** is read-only.
