Knowledge Base (AI Agent RAG Version)

This is the RAG-grounded version of the knowledge base. Content is the same product scope as the original, rewritten for clarity and consistency using IBM, Red Hat, and Microsoft technical writing principles. The original remains untouched at Knowledge Base (Documentation).

About this knowledge base

Use this knowledge base to complete everyday product tasks. Each section provides prerequisites, a short procedure, and a verification step so you can confirm the result.

  • Overview — Learn the product and portal capabilities and how they fit together.
  • Access control — Find what each role can do and choose the right role for a task.
  • Campaigns — Create disclosure campaigns and assign attestations to people or groups.
  • Data import — Import data, users, and roles from an XLSX template.

How to use this knowledge base

  1. Choose a section from the sidebar.
  2. Check Prerequisites at the top of the page.
  3. Follow Procedure step by step.
  4. Confirm completion in Verification.
