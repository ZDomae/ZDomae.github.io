## Account Admin

The **Account Admin** role is used for internal engineers to set up the product for new customers. 

| Section | Description |
| -------- | ------- |
| Admin Portal | Create and manage global settings and classes.| 
| Product | Manage and edit all sections in the product. |
| Users & Accounts | Create and manages users and groups. |
| Assessments | Create and manage operational acceptance testing assessment types.
| Reports | Import and export Power BI reports and templates.
| Dashboards | Import and export dashboards.

## Account Compliance Officer

The **Account Compliance Officer** is responsible for managing the **Compliance** part of the product.

| Section | Description |
| -------- | ------- |
| Admin Portal | Manage **Compliance** classes.| 
| Product | Restricted. |
| Users & Accounts | Create and manages users and groups for the **Compliance** product. |
| Assessments | Manage existing **Compliance** assessment types.
| Reports | Import and export Power BI reports and templates.
| Dashboards | Import and export dashboards.
